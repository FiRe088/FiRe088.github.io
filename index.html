Thesis

Neural Network Runtime Trade-offs: Scikit-learn vs. TensorFlow

Benchmarked training/inference runtime of scikit-learn (CPU) against TensorFlow (CPU and GPU) across structured (Wine, Adult, Higgs) and unstructured (20 Newsgroups, IMDb, Yelp) datasets, using equivalent MLP architectures. Two-way ANOVA showed both framework and data type had a significant effect on training time (F=139.26, F=43.06, both p<0.001), with a significant interaction between them — meaning the right framework choice depends on the data, not a universal answer. Dataset size was the only significant predictor of training time in multiple regression; learning rate and batch size were not, under the tested parameters.
